# Redes Neurais Artificiais

Repositório contendo atividades, exercícios e projetos desenvolvidos durante a disciplina Redes Neurais Artificiais da Universidade Federal de Alfenas (UNIFAL-MG).

## 📚 Sobre a disciplina

A disciplina de Redes Neurais Artificiais tem como objetivo apresentar os fundamentos e as principais arquiteturas de redes neurais, abordando desde os modelos mais simples até técnicas modernas de aprendizado profundo, com foco na aplicação prática desses modelos na resolução de problemas de classificação e reconhecimento de padrões.

Durante a disciplina foram desenvolvidas atividades práticas para aplicar os conceitos fundamentais de redes neurais na implementação de modelos utilizando a linguagem Python.

## 📖 Conteúdo abordado

- Introdução às Redes Neurais Artificiais
- Neurônio artificial e Perceptron
- Funções de ativação
- Redes Neurais Multicamadas (MLP)
- Treinamento e Backpropagation
- Redes Neurais Convolucionais (CNNs)
- Transfer Learning
- Ensemble de modelos
- Métricas de avaliação de modelos
- Explainable AI (XAI) — Grad-CAM e SHAP
- Desenvolvimento de sistemas de classificação com redes neurais

## 🚀 Projeto em destaque

### Classificação de Câncer de Mama com XAI

O principal projeto desenvolvido durante a disciplina foi um sistema de classificação de imagens histológicas de câncer de mama, com o objetivo de aplicar, na prática, os conceitos estudados ao longo da disciplina.

O projeto utiliza Redes Neurais Convolucionais com Transfer Learning (ResNet50 e EfficientNetB3), em uma abordagem de ensemble multi-magnificação, além de técnicas de explicabilidade (Grad-CAM e SHAP) para interpretar as decisões do modelo.

📁 O projeto pode ser encontrado na pasta:

```
breast_cancer/
```
